Getting started

Here are a few quick steps to get you started with the Collaborative OPen Omics (COPO) platform.
  1. COPO profile

    The first step is to create a work profile. A profile is a collection of research objects that form part of your project.

    To create a new profile: choose a profile type from the dropdown, then click next to it.

    If your desired profile type is not listed, please contact the COPO team.

  2. Profile components

    After creating a work profile you can start adding metadata by clicking any of the available components (files, samples, reads, annotations, etc.).
